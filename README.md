# Notes V1

Notes V1 is a lightning-fast, lightweight Windows desktop application designed to handle both standard text editing and structured data tracking in a single, multi-tabbed workspace.

## Two Unique Modes
- **Normal Notepad:** A clean, distraction-free environment for standard text editing.
- **Vehicle Tracker:** A specialized mode that structures your data into "tiles" for quickly tracking tags, addresses, residents, and visitors. 

---

## Step-by-Step Walkthrough

### 1. Getting Started
Launch `Notes V1.exe`. When the app opens, you will be prompted to choose how you want your first workspace tab to be formatted (Vehicle Tracker or Normal Notepad).

### 2. Managing Tabs
- **New Tab (`Ctrl + T`):** Open a brand new tab and select which mode you'd like it to be in. You can mix and match Tracker tabs and Notepad tabs in the same window!
- **Close Tab (`Ctrl + W`):** Close the currently active tab.

### 3. Using the Vehicle Tracker
In Vehicle Tracker mode, data is organized into blocks. You can instantly append new fields to any block using keyboard shortcuts:
- **`Alt + V`** - Add a Visitor Name
- **`Alt + C`** - Add a Company Name
- **`Alt + P`** - Add a Phone Number
- **`Alt + E`** - Add an Email Address
- **`Alt + S`** - Visual Save Alert (highlights the tile block to visually mark it as 'saved' or 'processed').

### 4. Saving & Opening Files
- **Save (`Ctrl + S`):** Save your active tab to a `.txt` file. 
- **Open (`Ctrl + O`):** Open an existing `.txt` file. 
- **Smart Auto-Detect:** You can double-click any `.txt` file directly from your Windows Desktop. Notes V1 will scan the file and automatically open it in Vehicle Tracker mode if it recognizes the structure, or Normal Notepad mode if it doesn't!

### 5. Searching for Data
Press **`Ctrl + F`** to open the search bar.
- Press `Enter` to jump to the **next** match.
- Press `Shift + Enter` to jump to the **previous** match.
- Press `Esc` to close the search bar.

### 6. Seamless Sessions
Never worry about losing your work! If you close the application, Notes V1 silently backs up your entire workspace. When you open the app again, it restores your exact tabs and completely unsaved text automatically.
